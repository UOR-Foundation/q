# Q's avatar

The Q orb from Hologram OS, rendered by its own engine (`apps/q/core/holo-orb.js`: a WebGPU raymarched volume) at 2500 × 2500 with a transparent background, then centred and downscaled so the sphere fills Discord's circular avatar crop edge to edge, like any profile picture; the faint outer glow falls outside the crop. Nothing here is upscaled.
